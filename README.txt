MON ÉQUILIBRE — PWA ANDROID

1. Décompressez le ZIP.
2. Publiez le contenu du dossier sur un hébergement statique HTTPS (par exemple GitHub Pages, Netlify ou Cloudflare Pages). Le fichier index.html doit être à la racine du site.
3. Ouvrez l'URL HTTPS sur Chrome Android.
4. Menu ⋮ > Installer l'application ou Ajouter à l'écran d'accueil.
5. L'application fonctionne ensuite hors ligne après le premier chargement complet.

IMPORTANT : ouvrir index.html directement depuis le gestionnaire de fichiers (file://) ne permet pas l'installation PWA. Ce ZIP est le code prêt à héberger, pas un site déjà publié.

Les données sont stockées localement dans le navigateur via localStorage. Utilisez Réglages > Exporter pour faire une sauvegarde avant de changer de téléphone ou d'effacer les données du navigateur.
