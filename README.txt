MON ÉQUILIBRE — INSTALLATION ANDROID (GRATUIT)

1. Décompresse le ZIP.
2. Crée un dépôt GitHub public et ajoute les 4 fichiers du dossier à la racine du dépôt.
3. Sur Netlify : Add new project > Import an existing project > GitHub, choisis ton dépôt et publie (pas de commande de build, répertoire de publication : .).
4. Ouvre l'adresse HTTPS Netlify sur Chrome Android.
5. Menu Chrome (⋮) > Installer l'application ou Ajouter à l'écran d'accueil.
6. Utilise l'application même hors connexion après la première ouverture.

Données : enregistrées localement sur le téléphone, sans compte et sans serveur. Dans Réglages, utilise Exporter une sauvegarde régulièrement. Supprimer les données du navigateur peut effacer le planning.

Le planning initial est indicatif et modifiable en supprimant/ajoutant des activités. Le suivi mensuel utilise la liste actuelle des objectifs.
